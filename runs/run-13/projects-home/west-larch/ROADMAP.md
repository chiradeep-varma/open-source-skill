# Roadmap

- **M0 — skeleton.** Project scaffold, SQLite schema + migrations, launcher config. *(done)*
- **M1 — core loop.** Sign up/log in, profile editing, link CRUD + reorder + hide, public page, atomic click tracking, per-link/profile analytics, 5 themes, QR code. *(done, this session)*
- **M2 — switch-blockers.** Custom-domain self-hosting docs (reverse proxy + DNS), CSV export of a user's own links.
- **M3 — differentiators.** Scheduled links, embedded video link type, referrer/device/geo analytics with a real events table, avatar upload instead of URL-only.
- **Later / won't.** Commerce and checkout, seller fees, Instagram/TikTok automation — see `docs/product/parity-matrix.md` for the full list and reasoning.
