# Importing your data

There's no automated importer from Linktree or any other service in this release — see `docs/product/parity-matrix.md`, which lists it as `Won't`: Linktree doesn't publish a data export format, and scraping a live competitor page for a handful of links isn't worth building.

In practice, moving over is quick by hand:

1. Open your existing link-in-bio page and note each link's title and URL, in order.
2. Sign up here, then on the dashboard use **Add link** for each one — reordering afterward with the up/down arrows if needed.
3. Set your display name, bio, avatar URL and theme on the same dashboard.
4. Update your social bios to point at your new page's URL (shown at the top of the dashboard, with a QR code for mobile).

If demand shows up for a specific source format (for example, a CSV a user exported from somewhere), a small importer is a reasonable `Later` addition — see `ROADMAP.md`.
