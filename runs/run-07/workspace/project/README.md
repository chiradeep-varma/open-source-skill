# Fenline (working name)

An open-source, self-hostable issue tracker and project-management tool for small software engineering teams — an alternative to [Linear](https://linear.app), built independently, with no per-seat paywalls on SSO, guest access, or custom fields.

**Status: planning stage.** This repository currently holds research and a plan, not code. See `ROADMAP.md` for what's next.

Not affiliated with or endorsed by Linear. "Linear" is a trademark of its owner, used here only to identify the product this project offers an open-source alternative to.
