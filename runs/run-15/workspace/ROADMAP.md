# Roadmap

- **M0 — skeleton**: project scaffold, SQLite schema + migrations, admin auth, empty public page.
- **M1 — core loop** (this build): components CRUD, incidents + updates + resolve, public status page with overall banner, incident history.
- **M2 — switch-blockers / cheap openness wins** (this build): scheduled maintenance, read-only JSON API, RSS/Atom feed of incidents.
- **M3 — differentiators / later**: email notifications, uptime metrics from an external monitor, multi-admin accounts, component groups drag-reorder.

See `docs/product/parity-matrix.md` for the full feature-by-feature status.
