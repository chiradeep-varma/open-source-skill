# Code of Conduct

Corkboard is a small project. The expectation is simple: be respectful,
assume good faith, and keep discussion focused on the work.

- Disagreement about technical decisions is normal and welcome — make your
  case with reasoning, not repetition or escalation.
- Personal attacks, harassment, discriminatory language, or deliberately
  derailing discussion are not welcome, in issues, PRs, or any other
  project space.
- Maintainers may edit, close, or lock discussions that violate this, and
  may ban repeat offenders from the project.

If something happens that you think maintainers should know about privately
rather than in a public issue, open an issue titled clearly as
confidential, or reach out to a maintainer directly if contact details are
listed for the project.

This is intentionally short. If it stops being enough as the project and
community grow, it should be extended then — not preemptively.
