# Parity Matrix

Tiers: **Core** (job fails without it) · **Switch-blocker** (needed to leave Trello)
· **Differentiator** (the better-thesis) · **Later** · **Won't** (out of scope).

| Feature | Tier | Status |
|---|---|---|
| Boards, lists, cards | Core | Built |
| Drag & drop cards between/within lists | Core | Built |
| Drag & drop / reorder lists | Core | Built |
| Card detail: description, due date | Core | Built |
| Labels (create, color, apply, filter) | Core | Built |
| Assign members to cards | Core | Built |
| Checklists on cards | Core | Built |
| Comments on cards | Core | Built |
| Archive / delete boards, lists, cards | Core | Built |
| Auth (email + password), seeded team | Core | Built |
| Board membership / visibility | Core | Built |
| Full JSON export of all data | Differentiator | Built |
| Trello JSON import | Switch-blocker | Built (basic: boards/lists/cards/labels/checklists/comments) |
| One-command self-host (Docker Compose) | Differentiator | Built |
| No per-seat pricing / flat self-hosted install | Differentiator | Built (inherent to self-hosting model) |
| Card attachments (file upload) | Later | Not built |
| Real-time multi-user sync (WebSockets) | Later | Not built (polling/optimistic UI instead) |
| Power-Ups / third-party integrations | Won't | Not built |

| Calendar / Timeline / Table / Map / Dashboard views | Later | Not built |
| SSO / SCIM / audit log / enterprise admin | Won't | Not built |
| Multi-workspace billing / plan tiers | Won't | N/A — self-hosted, not SaaS |
